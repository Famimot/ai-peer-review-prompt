# Промпт для ИИ-рецензирования

**Версия:** 5.1 (250326.51)  
**Автор:** Кравцов Г.Г.  
**Модель ИИ:** DeepSeek  
**Языки:** русский / английский

## Описание

Универсальный промпт для предварительного рецензирования научных рукописей. Реализует 100-балльную взвешенную метрику (новизна 30%, методология 25%, практическая ценность 20%, визуализация 15%, этика 10%) с дифференциацией типов новизны (I/P-Novelty) и обязательной контекстуальной калибровкой на массиве статей.

## Использование

1. Создайте новый диалог в DeepSeek
2. Скопируйте текст промпта из файла `Universal_AI_Review_Prompt_v_51_RU.txt` (или `EN`)
3. Передайте его ИИ вместе с рукописью(ями) для рецензирования
4. ИИ сгенерирует структурированную рецензию в соответствии с алгоритмом

**Время выполнения:** 1.5–2 минуты на 4 статьи среднего размера.

## Состав файлов

- `Universal_AI_Review_Prompt_v_51_RU.txt` — калиброванный (рус.)
- `Universal_AI_Review_Prompt_v_51_EN.txt` — калиброванный (англ.)
- `Simple_AI_Review_Prompt_RU.txt` — простой, некалиброванный (для справки)
- `Supplementary_Validation_Data.xlsx` -  — валидация метода
- `DEMO_AMIS_peer_review_4_papers_2026_RU.doc` — пример ИИ-рецензии (https://doi.org/10.5281/zenodo.19275632)
