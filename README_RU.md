# Промпт для ИИ-рецензирования

**Версия:** 5.1 (250326.51)  
**Автор:** Кравцов Г.Г.  
**Модель ИИ:** DeepSeek  
**Языки:** русский / английский

## Описание

Универсальный промпт для предварительного рецензирования научных рукописей. Реализует 100-балльную взвешенную метрику (новизна 30%, методология 25%, практическая ценность 20%, визуализация 15%, этика 10%) с дифференциацией типов новизны (I/P-Novelty) и обязательной контекстуальной калибровкой на массиве статей.

## Использование

1. Создайте новый диалог в DeepSeek
2. Скопируйте текст промпта из файла `Universal_AI_Review_Prompt_v_51_EN.txt`
3. Передайте его ИИ вместе с рукописью(ями) для рецензирования
4. ИИ сгенерирует структурированную рецензию в соответствии с алгоритмом

**Примерное время выполнения:** 1.5–2 минуты на 4 статьи среднего размера.

## Доступность данных

Все материалы для воспроизведения результатов находятся в открытом доступе:

### Промпты (Prompts)
- `Universal_AI_Review_Prompt_v_51_RU.txt` — калиброванная версия (русский)
- `Universal_AI_Review_Prompt_v_51_EN.txt` — калиброванная версия (английский)
- `Simple_AI_Review_Prompt_RU.txt` — простой некалиброванный промпт (для справки)

### Валидационные данные
- `validation/Supplementary_Validation_Data.xlsx` — валидация метода (10 прогонов простого и калиброванного промптов)
- Анализируемая статья: https://doi.org/10.5281/zenodo.19275632

### Пример (example)
- `DEMO_AMIS_peer_review_4_papers_2026_RU.doc` — пример ИИ-рецензии (https://doi.org/10.5281/zenodo.19275632)

### Субпромпты (subprompts)
- `subprompts/` — модульные промпты для анализа отдельных разделов (заголовок, аннотация, введение и т.д.)
