# Узкий промпт: Анализ тривиальности

## Признаки тривиальности (проверять)

- [ ] Цель сформулирована как "изучить", "рассмотреть", "проанализировать" без конкретики
- [ ] Нет явной проблемы, которую решает исследование
- [ ] Методы стандартные, без обоснования выбора
- [ ] Результаты очевидны и предсказуемы
- [ ] Отсутствуют количественные данные
- [ ] Выводы повторяют введение
- [ ] Литература преимущественно устаревшая (>10 лет)
- [ ] Преобладают самоцитирования (>30%)
- [ ] Объём статьи не соответствует содержанию (много воды)
- [ ] Структура формальная, но внутренние связи отсутствуют

## Шкала тривиальности

| Балл | Уровень |
|------|---------|
| 0–20 | Оригинальная |
| 21–50 | Пограничная |
| 51–80 | Формальная |
| 81–100 | Тривиальная |
