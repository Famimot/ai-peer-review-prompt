# Узкий промпт: Анализ результатов

## Назначение
Оценить качество раздела, представляющего результаты исследования, с учётом контекста полного текста, методологии и результатов глобального анализа. Выявить обоснованность, полноту и соответствие результатов заявленным целям.

## Идентификация раздела
Раздел результатов может называться:
- "Результаты"
- "Results"
- "Результаты исследования"
- "Эмпирические результаты"
- "Findings"

Анализируется весь блок, содержащий изложение полученных данных, независимо от точного названия.

## Входные данные
- Текст раздела результатов (из статьи)
- Полный текст статьи (для контекста)
- Раздел методологии (для проверки соответствия)
- Результаты глобального анализа (тип статьи, ключевые выводы)

## Критерии оценки

| Критерий | Вес | Шкала | Что проверять |
|----------|-----|-------|---------------|
| Соответствие целям | 25% | 0-5 | Отвечают ли представленные результаты на поставленные во введении вопросы? Соответствуют ли заявленной цели? |
| Полнота представления | 20% | 0-5 | Представлены ли все результаты, необходимые для обоснования выводов? Есть ли количественные данные? |
| Визуализация и наглядность | 15% | 0-5 | Качественно ли представлены графики, таблицы, карты? Есть ли ссылки на них в тексте? |
| Статистическая корректность | 15% | 0-5 | Корректно ли использованы статистические методы? Указаны ли меры изменчивости, размеры эффектов? |
| Связь с методологией | 15% | 0-5 | Соответствуют ли результаты описанным методам обработки? Прозрачно ли, как получены данные? |
| Объективность интерпретации | 10% | 0-5 | Нет ли переоценки значимости результатов? Отличаются ли выводы от того, что показывают данные? |

## Обязательные элементы (для проверки)

| Элемент | Должен присутствовать | Примечание |
|---------|----------------------|------------|
| Количественные результаты | ✅ | Числовые значения, метрики |
| Визуализация | ⚠️ | Графики, таблицы (для эмпирических работ) |
| Ссылки на визуализацию | ✅ | Каждый рисунок/таблица должны быть упомянуты в тексте |
| Сравнение с базой/эталоном | ⚠️ | Если применимо |
| Статистические показатели | ⚠️ | Для количественных исследований |
| Подразделы по логике | ⚠️ | Группировка результатов по темам/гипотезам |

## Типичные недостатки (для проверки)

- [ ] Результаты не соответствуют заявленным целям
- [ ] Приведены только "интересные" результаты, неполнота
- [ ] Нет количественных данных (только общие фразы)
- [ ] Визуализация не соответствует описанию
- [ ] Нет связи между результатами и методологией
- [ ] Интерпретация выходит за пределы данных
- [ ] Отсутствуют отрицательные/нулевые результаты (если применимо)

## Примечание
