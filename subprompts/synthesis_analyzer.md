# Узкий промпт: Синтез сводной рецензии

## Назначение
Собрать результаты всех предыдущих анализов (глобального и по разделам) в единую структурированную рецензию, соответствующую требованиям глобального промпта. Сформировать итоговый документ с рекомендацией.

## Входные данные
- Результаты глобального анализа (общая оценка, тип статьи, категория, сильные и слабые стороны)
- Результаты анализа заголовка
- Результаты анализа аннотации
- Результаты анализа введения
- Результаты анализа методологии
- Результаты анализа результатов
- Результаты анализа заключения
- Результаты анализа литературы и дополнительных материалов

## Структура итоговой рецензии

### 1. Краткое содержание
2-3 предложения о сути работы, предмете, методе, основных результатах.

### 2. Актуальность исследования
Оценка обоснования проблемы, значимости для области.

### 3. Научная новизна
- Определение типа новизны (I-Novelty / P-Novelty)
- Обоснование новизны
- Оценка по критериям P-Novelty (если применимо): логическая целостность, преодоление ограничений традиционных подходов, потенциал для исследовательской программы

### 4. Методологическая корректность
- Оценка методологии с учётом типа новизны
- Для P-Novelty: адекватность метода, масштаб эмпирической базы, прозрачность, воспроизводимость

### 5. Достоверность результатов
- Соответствие результатов целям
- Полнота представления
- Статистическая корректность
- Связь с методологией

### 6. Качество визуализации и оформления
- Оценка графиков, схем, иллюстраций
- Наличие и корректность ссылок на них в тексте
- Единообразие оформления

### 7. Этические аспекты и открытость
- Наличие дополнительных материалов
- Открытость данных и кода
- Соответствие FAIR-принципам
- Декларация конфликта интересов

### 8. Сводная оценка по критериям

| Критерий | Оценка (из анализов) | Вес | Вклад |
|----------|---------------------|-----|-------|
| Научная новизна | X/30 | 30% | X |
| Методологическая строгость | X/25 | 25% | X |
| Практическая ценность | X/20 | 20% | X |
| Качество визуализации | X/15 | 15% | X |
| Этические аспекты | X/10 | 10% | X |
| **Итого** | **X/100** | **100%** | |

*Примечание: оценки берутся из глобального анализа с учётом уточнений из узких анализов.*

### 9. Итоговый балл и его интерпретация
- Итоговый балл: ___ из 100
- Категория: <50 / 50-70 / 70-90 / 90-100
- Рекомендация: Отклонить / Принять после доработки / Принять с незначительными замечаниями / Принять (высший стандарт)

### 10. Тип документа и категория
- Тип: А / Б / В / Г (расшифровка)
- Обоснование

### 11. Рекомендация по уровню журнала
- Q1 / Q2 / Q3 / Q4

### 12. Основные замечания (сводка)
Перечень выявленных слабостей из всех анализов (не более 5-7 пунктов)

### 13. Рекомендации по доработке (сводка)
Перечень рекомендаций из всех анализов (приоритетные, не более 5-7 пунктов)

## Формат вывода

Итоговая рецензия оформляется в виде единого документа, следуя структуре выше. Язык: русский (или английский в соответствии со статьёй). В конце добавляется обязательная фраза:

*"Рецензия создана с использованием системы искусственного интеллекта DeepSeek-V3 на основе универсального промпта v.250825.31 (автор Kravtsov G.) в демонстрационных и образовательных целях, сохраняя полное соответствие требованиям ГОСТ Р 7.0.100-2018 к научным рецензиям."*

## Примечание
Синтез выполняется на основе всех ранее выполненных анализов. Если между глобальной и узкими оценками есть расхождения, приоритет отдаётся узким анализам как более детальным. Итоговая оценка может отличаться от глобальной.
